# قالب فاکتور فروش طلا و جواهر

قالب فاکتور A4 تک‌صفحه‌ای (فارسی/RTL) برای طلا و جواهر. خروجی PDF کاملاً برداری است
و فونت‌ها داخل فایل جاسازی می‌شوند، بنابراین در هر بزرگ‌نمایی و در هر چاپی شارپ می‌ماند.

## فایل‌ها
- `template.html` — قالب و تمام استایل‌ها (متن، رنگ‌ها، چیدمان اینجا ویرایش می‌شود)
- `build.py` — داده‌های فاکتور (نرخ طلا، اقلام، اجرت، سود، مالیات) و تولید HTML نهایی
- `fanum.py` — اعداد فارسی، جداکننده هزارگان و تبدیل مبلغ به حروف
- `Gold-Jewelry-Invoice-A4.pdf` — خروجی نمونه (پرشده)
- `Gold-Jewelry-Invoice-BLANK-A4.pdf` — خروجی فرم خام
- `Gold-Invoice-FILLABLE.html` — نسخه قابل تایپ در مرورگر (خودکفا، آفلاین، با محاسبه خودکار)
- `formvars.py` — فیلدها، استایل و اسکریپت نسخه قابل تایپ

## ساخت مجدد
```bash
# ۱) فونت‌ها (Vazirmatn + Cormorant Garamond)
curl -sSL -o vazirmatn.tgz https://registry.npmjs.org/vazirmatn/-/vazirmatn-33.0.3.tgz
tar xzf vazirmatn.tgz --wildcards 'package/fonts/webfonts/*'
curl -sSL -o cg.tgz https://registry.npmjs.org/@fontsource/cormorant-garamond/-/cormorant-garamond-5.2.5.tgz
mkdir -p cg && tar xzf cg.tgz -C cg --wildcards 'package/files/cormorant-garamond-latin-*-normal.woff2'

# ۲) تولید HTML  (INVOICE_BASE = پوشه‌ای که package/ و cg/ در آن است)
INVOICE_BASE="$PWD" python3 build.py            # نمونه پرشده -> invoice.html
INVOICE_BASE="$PWD" python3 build.py --blank    # فرم خام     -> invoice-blank.html
INVOICE_BASE="$PWD" python3 build.py --form     # قابل تایپ   -> invoice-form.html

# ۳) تبدیل به PDF
chromium --headless --no-pdf-header-footer \
  --run-all-compositor-stages-before-draw --virtual-time-budget=8000 \
  --print-to-pdf=Gold-Jewelry-Invoice-A4.pdf "file://$PWD/invoice.html"
```

## فرمول محاسبه هر ردیف
```
ارزش طلا           = وزن (گرم) × نرخ هر گرم
اجرت ساخت          = ارزش طلا × درصد اجرت
سود فروشنده        = (ارزش طلا + اجرت) × درصد سود
اجرت و کارمزد ساخت = اجرت ساخت + سود فروشنده      ← تنها چیزی که چاپ می‌شود
مالیات ارزش افزوده = اجرت و کارمزد × ۱۰٪          ← فقط بر اجرت و کارمزد، نه بر خود طلا
مبلغ ردیف          = ارزش طلا + اجرت و کارمزد + سنگ و نگین + مالیات
```

سود فروشنده به‌صورت عمدی در ستون «اجرت و کارمزد ساخت» ادغام شده و هیچ ستون، درصد یا
عبارتی روی فاکتور چاپ‌شده وجود ندارد که بتوان از آن حاشیه سود را استخراج کرد؛ در عین حال
تمام جمع‌ها دقیق و قابل راستی‌آزمایی برای خریدار باقی می‌ماند (هر مقدار پیش از جمع گرد می‌شود).
در نسخه قابل تایپ، درصد اجرت و درصد سود در فیلدهای «چاپ‌نشدنی» وارد می‌شوند و سود کل فقط
روی نوار بالای صفحه به خود فروشنده نمایش داده می‌شود.
درصد سود، نرخ مالیات و نرخ روز طلا در بالای `build.py` قابل تغییر است.

## بندهای شرایط فروش
بندهای پای فاکتور (بخش `terms-b` در `template.html`) با جهت‌گیری حمایت از فروشنده نوشته شده‌اند:
اسقاط کافه خیارات، تأیید توزین و عیار در زمان تحویل، عدم پذیرش مرجوعی کالای سالم، مبنای بازخرید
بر پایه نرخ خرید روز، ضبط بیعانه به‌عنوان وجه التزام، حفظ مالکیت تا تسویه کامل، وجه التزام تأخیر،
اعتبار محدود نرخ، ضمانت محدود، انحصار مستندات به فاکتور و دفاتر فروشگاه، و تعیین مرجع حل اختلاف.

سه جای خالی باید پیش از چاپ پر شود: درصد وجه التزام تأخیر (بند ۸) و مدت ضمانت (بند ۱۰).
